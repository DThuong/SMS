# Tiến độ ngày 26/10/2026 (Thứ Hai)

> **Ghi chú (28/10):** frontend React và các trang quản trị mô tả trong file này đã bị bỏ; SMS nay chỉ còn backend API + agent. Xem [2026-10-28](2026-10-28.md).

## 1. Tóm tắt

- Khởi tạo dự án **SMS (Scan MES System)**: tool tự động lấy dữ liệu từ hệ thống MES của công ty (không có quyền truy cập DB của MES), lưu thành file và về sau đẩy sang **DYS**.
- Khảo sát kỹ thuật MESClient: xác định công nghệ, cách đọc được dữ liệu **mà không chiếm chuột**.
- Viết xong **collector** lấy kế hoạch sản xuất (View Work Order) cho 2 xưởng **SMD (Oper 2010)** và **MAINLINE (Oper 3010)**.
- Lên kế hoạch và **dựng xong backend (Django + MySQL) + frontend (React)** có trang quản trị, database, worker chạy theo lịch.

## 2. Mục tiêu dự án

1. **Kế hoạch sản xuất:** tự động lấy Work Order từ MES, tách theo xưởng, lưu file, đẩy lên DYS, lịch chạy cố định 8:00 sáng.
2. **Sản lượng sản xuất:** lấy dữ liệu sản lượng trên MES lúc 8:00 sáng (chưa làm, cần màn hình MES tương ứng).
3. Về sau: AI agent tự khám phá giao diện MES và lưu context/runbook vào database.

## 7. Kế hoạch đã chốt cho giai đoạn tiếp theo

- **Cấu trúc:** `backend/` (Django 5) + `frontend/` (React + Vite + TypeScript). Collector chuyển vào `backend/apps/collector/`.
- **Backend:** Django, django-ninja (API), **MySQL 8** (`mysqlclient`, dự phòng `PyMySQL`, bảng mã `utf8mb4`), django-q2 (job nền + lịch), django-unfold (admin).
- **Frontend:** React, TanStack Query/Table, shadcn/ui + Tailwind, Recharts, react-router, i18n.
- **Bảng dữ liệu:** `core_oper`, `core_setting`, `jobs_job`, `jobs_jobrun`, `jobs_jobrunstep`, `plans_exportfile`, `plans_workorder`, cùng bảng user/phân quyền của Django và bảng của django-q2.
- **Trang:** Đăng nhập, Dashboard, Jobs, Lịch sử chạy (timeline từng bước), Kế hoạch Work Order, Files, Cài đặt; `/admin` để sửa trực tiếp.
- **Chạy nền:** worker chạy trong phiên Windows đang đăng nhập (Task Scheduler khởi động khi logon); mỗi lúc chỉ một job thao tác MES.
- **DYS:** tạm tắt đẩy dữ liệu cho tới khi DYS có endpoint; file giữ N ngày rồi tự xóa.

## 8. Phần 2 (chiều): dựng backend + frontend + database

### Quyết định đã chốt
- Database: **MySQL 8** chạy ngay trên máy MESClient (`localhost:3306`), DB `sms`, bảng mã `utf8mb4`.
- Giao diện: **chỉ tiếng Việt**.
- **Lưu từng dòng Work Order vào DB** (bảng `plans_workorder`) ngoài file Excel.
- **Thay đổi so với kế hoạch:** không dùng django-q2, thay bằng **worker tự viết** (`manage.py run_worker`).
  Lý do: django-q2 trên Windows chạy job trong tiến trình con, dễ xung đột với COM/UI Automation.
  Worker tự viết chỉ có 1 tiến trình, đọc lịch cron và hàng đợi trong MySQL, dễ đọc để học.
- Bỏ TanStack Table (bảng tự viết đủ dùng), dùng font Be Vietnam Pro đóng gói sẵn (chạy được không cần internet).
