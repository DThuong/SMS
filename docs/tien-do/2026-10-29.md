# Tiến độ ngày 29/10/2026 (Thứ Năm)

## 1. Tóm tắt trong ngày

1. **Sửa lỗi `MES_MENU_NOT_FOUND`** khi chạy `run_job PRODUCTION_OUTPUT`: agent so tên menu linh hoạt hơn
   (bỏ `&`, khoảng trắng thừa, ngoặc full-width, không phân biệt hoa thường, bỏ tiền tố `[..]`, cuối cùng thử "chứa tên").
   Không tìm thấy thì lỗi ghi kèm **danh sách menu MES đang thấy**.
2. **Gọn database:** 10 bảng → 9 bảng, đổi tên dễ hiểu (bỏ tiền tố `core_`, `jobs_`, `plans_`).
   Gộp `plans_exportfile` + `plans_productionreport` thành **`files`** (cột `kind` = `workorder` / `production`).
3. **Gọn API:** bỏ nhóm `/api/integrations/*` (trùng với `/api/jobs/{code}/run` và `/api/runs/{id}`);
   bỏ `/api/production-reports/*`, `/api/workorders/exports` → dùng chung `/api/files`.
   Mật khẩu API đổi thành **API key** (header `X-Api-Key`, query `?api_key=`).

## 2. Đổi tên bảng

| Cũ | Mới |
|---|---|
| `core_apipassword` | `api_keys` (cột `password_hash` → `key_hash`) |
| `core_setting` | `settings` |
| `core_oper` | `opers` |
| `jobs_job` | `jobs` |
| `jobs_jobrun` | `job_runs` |
| `jobs_jobrunstep` | `job_logs` |
| `jobs_workerheartbeat` | `worker_status` |
| `plans_exportfile` + `plans_productionreport` | `files` |
| `plans_workorder` | `work_orders` (cột `export_file_id` → `file_id`) |

Vì sao job vẫn 3 bảng: `jobs` = định nghĩa (3 dòng cố định), `job_runs` = mỗi lần chạy, `job_logs` = từng dòng nhật ký
của một lần chạy. Quan hệ 1 → nhiều, gộp lại sẽ lặp dữ liệu.

## 3. Đổi API

| Cũ | Mới |
|---|---|
| `X-Api-Password` / `?password=` | `X-Api-Key` / `?api_key=` |
| `POST /api/integrations/production-output/run`, `/integrations/jobs/{code}/run`, `/jobs/{id}/run` | `POST /api/jobs/{code}/run` |
| `GET /api/integrations/runs/{id}` | `GET /api/runs/{id}` (có `logs`, `files`, `finished`, `worker_online`) |
| `PUT /api/jobs/{id}` | `PUT /api/jobs/{code}` |
| `GET /api/runs/{id}/steps` | `GET /api/runs/{id}/logs` |
| `/api/production-reports/...` | `/api/files?kind=production`, `/api/files/{id}/download`, `/api/files/{id}/import-result` |
| `GET /api/workorders/exports?oper=` | `GET /api/files?kind=workorder&oper=` |
| `GET /api/workorders?export_file_id=` | `GET /api/workorders?file_id=` |
| `PUT/DELETE /api/opers/{id}` | `PUT/DELETE /api/opers/{code}` |
| Trạng thái file `ready` / `deleted` | `saved` + cờ `file_deleted` |

## 4. Việc cần làm trên máy MES
1. Workbench: chạy `sql/reset_database.sql` (xóa sạch DB cũ).
2. `python manage.py migrate` → `python manage.py seed` (hoặc `docker compose up -d --build`).
3. Sửa rồi chạy `sql/setup_after_migrate.sql` (tài khoản MES + API key) hoặc `python manage.py api_key add "Tên"`.
4. Chạy lại `python manage.py run_job PRODUCTION_OUTPUT` để kiểm tra phần sửa menu.
